# Encantos Literários - Landing Page

> Projeto desenvolvido por **Evelyn Bezerra Ramos**.

## 📖 Sobre o Projeto

Esta é uma landing page para um clube de assinatura de livros fictício chamado "Encantos Literários". O objetivo da página é atrair novos assinantes, apresentando o serviço, os benefícios de fazer parte do clube e os diferentes planos de assinatura disponíveis.

O design é focado em uma temática mística e encantadora para criar uma experiência imersiva para o visitante.

## ✨ Funcionalidades

A página está dividida nas seguintes seções:

- **Hero:** Seção de boas-vindas com o slogan principal do clube.
- **Sobre:** Uma breve descrição da experiência de receber um livro surpresa e brindes exclusivos todos os meses.
- **Kit Mensal:** Apresentação visual dos itens que podem compor o kit do assinante.
- **Planos de Assinatura:** Detalhamento dos planos Mensal, Semestral e Anual, com destaque para o plano mais popular.
- **Rodapé:** Contém links para redes sociais e outras seções importantes como "Ajuda" e "Conteúdos".

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias:

- **HTML5:** Para a estruturação e semântica do conteúdo.
- **CSS3:** Para estilização, layout (Flexbox, Grid) e animações.
- **JavaScript:** Para futuras interatividades na página.
